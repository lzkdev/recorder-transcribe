# 状态与恢复

状态独立于文件名，按有效源文件 SHA-256 存放。以原子替换写 JSON，进程锁避免本机并发重复提交。

| 状态 | 含义 | 重跑 |
|---|---|---|
| new | 尚未提交 | 可提交 |
| uploading | 上传调用前已记录意图，尚无确定响应 | 停止；核对云空间 |
| uploaded | file_token 已保存 | 只创建妙记 |
| creating | 创建请求可能已到达飞书，但响应未保存 | 停止；核对妙记列表 |
| pending | minute_token 已保存，产物未完整取得 | 只读查询同一个妙记 |
| done | 逐字稿存在且有正文 | 返回 cached |
| empty_result | 逐字稿为空或只有导出标题 | 不当作成功，不重新提交 |

上传/创建不自动重试。若确认远端已创建，备份 `state.json` 后补入核实得到的 `file_token`、`minute_token`、`minute_url`，并将状态设为 `pending` 后重跑。仅上传完成则补 `file_token` 并设为 `uploaded`。若确定没有创建，可备份并移走该条状态后重试。无法确定就保留状态，不删除记录碰运气。

不提供旧版 `--force`；避免一键批量重复消费。旧版 `transcribed.json` 保留不动，不自动迁移到 v2；首次使用 v2 前人工核对历史妙记，避免再次提交旧录音。

退出码：0 完成/缓存/本地验证通过；1 错误或初始化阻塞；2 尚在处理、需要用户确认或产物为空。批量为每个输入输出独立 JSON 行。校验失败会明确记为 error，不伪装为成功。逐字稿就绪并不保证 AI 总结非空，也不证明识别准确率。

状态目录含录音名称、绝对路径、逐字稿和妙记链接，默认只供本机用户读取。跨账户使用独立状态目录；不要并行复制状态目录以绕过锁。CLI 上游内部重试策略不由此项目控制，本项目仅保证不主动重复调用写命令。
